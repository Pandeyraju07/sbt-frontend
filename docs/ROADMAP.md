# SBT frontend roadmap

This follows the phased implementation approach defined for SBT. **Phase 1 is the only phase in this repository right now.**

| Phase | Name                       | Frontend focus                                        |
| ----- | -------------------------- | ----------------------------------------------------- |
| 1     | Frontend Foundation        | Tooling, design system, shells, routing, API seams    |
| 2     | Identity & Users           | Login, register, session, profile                     |
| 3     | Seller Organization        | Organization creation and settings                    |
| 4     | Store Management           | Multi-store administration                            |
| 5     | Employees & Permissions    | RBAC and scoped permissions UI                        |
| 6     | Categories & Configuration | Catalog configuration                                 |
| 7     | Product Catalog            | Products and variants                                 |
| 8     | Media System               | Images, videos, file management                       |
| 9     | Product Review             | Product approval workflows                            |
| 10    | Inventory                  | Stock and availability                                |
| 11    | Admin Control Plane        | Verification, store/product approval, policies, audit |
| 12    | Buyer Platform             | Buyer-facing marketplace                              |

Do not start Phase 2 until this foundation is accepted.
